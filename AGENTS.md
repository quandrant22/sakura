# Инструкции для ИИ-агентов (AI Agents Guidelines)

Добро пожаловать в проект «Сакура». Перед началом работы и внесением изменений обязательно ознакомьтесь с правилами репозитория:

- **[Политика деплоя и синхронизации с VPS](.agent/rules/git-deploy-policy.md)** (`.agent/rules/git-deploy-policy.md`):
  - **Строго запрещён прямой деплой через `scp`/`sftp`/`rsync`/ручное копирование** в обход Git.
  - Деплой на VPS осуществляется **исключительно** через цикл: `pytest` локально → осмысленный `git commit` → `git push` → `git pull` на VPS → проверка компиляции → `systemctl restart sakura.service`.
  - Рабочее дерево на сервере всегда должно оставаться чистым (`git status`).
