# UI — темы, каркас и экраны

Источник токенов в коде — `desktop/ui/tailwind.config.js` (имена) и `desktop/ui/src/index.css`
(значения тем). Меняешь там — меняй здесь. Цвета в компонентах — только токены.
Референс — набросок владельца (кадр 1440×1024) из описания задачи.

## Темы

| Токен | «Сакура-ночь» (по умолчанию) | «Как в наброске» | Где |
|---|---|---|---|
| `bg` | `#0a0610` | белый | фон окна |
| `bar` | как `bg` | чёрный | верхняя панель |
| `panel` | `#14101c` | чёрный | карточки |
| `panel2` | `#1d1628` | `#1c1c1e` | вложенные панели, поля, наведение |
| `line` | `rgba(255,255,255,.07)` | `rgba(255,255,255,.12)` | границы |
| `ink` / `ink-dim` | `#f1e9f5` / `#9b8fa8` | `#f5f5f5` / `#a5a5aa` | текст |
| `accent` → `accent-deep` | `#FF6AE3` → `#3E0074` | так же | `bg-accent-grad`: активный пункт, кнопки |
| `accent-soft` | `rgba(255,106,227,.16)` | так же | подсветка, свечение |
| `online` | `#3ddc97` | так же | «онлайн», точка связи |
| `rounded-card` | 20 px | | карточки (rx 20 в наброске) |
| `rounded-btn` | 12 px | | кнопки, пункты меню |
| `gap` / `edge` | 20 / 30 px | | зазоры / поля окна |

Тема выбирается в Настройках → «Интерфейс» и хранится в `layout.json` (по device_id).
При `prefers-reduced-motion: reduce` переходы отключаются (`index.css`), ядро-графика замирает.

## Окно

- Базовый размер 1440×1024 (не больше рабочей области), минимум 1180×760, без системной рамки.
- Перетаскивание за пустой центр верхней панели (`.drag`), кнопки — `.no-drag`.

## Каркас (кадр 1440×1024)

```

│ [✿ SAKURA] 300×45                      перетаскивание          [–][□][×] 45 │
├──────────────┬───────────────────────────────────┬──┬──────────────────────┤
│ ядро 300×287 │ доска виджетов (react-grid-layout)│  │ чат на всю высоту    │
│  капля (150,98)│ система 9×16   │ видео 15×16     │ ↔│ 350 px (320…60%)     │
│  Sakura      ├────────────────┴──────────────────┤  │ подсказки            │
│  ● Онлайн    │ окно приложения 24×11             │  │ [🎤 сообщение…  ➤]   │
├──────────────┤                                   │  │                      │
│ меню 300×583 ├───────────────────────────────────┤  │                      │
│ 5 пунктов    │ музыка 24×4 (панель 100 px)       │  │                      │
│ v1.0.0     ● │                                   │  │                      │
└──────────────┴───────────────────────────────────┴──┴──────────────────────┘
поля 30, зазоры 20
```

- **Ядро** (`core-gfx/SakuraCore.tsx`): size 260, центр капли (150, 98) от угла карточки.
  Клик — `listen_now` («говорить сейчас»), удержание 600 мс или клавиша M — микрофон.
  Статус: Онлайн / Слушаю / Думаю / Говорю / Нет связи; под ним — пояснение (нет связи
  с ядром или сервером, загрузка распознавания).
- **Меню**: Главная, Устройства, Сценарии, Память, Настройки (260×35, шаг 50). На главной
  под пунктами — инструменты доски: «Правка доски», замок, в режиме правки — вернуть
  убранные виджеты и «Сбросить раскладку».
- **Доска**: 24 колонки, `rowHeight` 9.35, отступ 20, без схлопывания вверх и без наложения,
  перетаскивание за заголовок, изменение размера за угол. Уже 690 px — масштабируется целиком.
- **Чат**: разделитель тянется мышью; двойной клик — 350 px; кнопка в заголовке сворачивает
  в полосу 56 px. Сообщения — текстом, markdown не интерпретируется.

Сверка с наброском: `npm run build`, затем `electron scripts/compare-sketch.cjs [папка]` —
`sketch.png`, `frame.png`, `overlay.png` (контуры наброска поверх снимка), `compare.json`.

## Экраны

- **Устройства**: список устройств, метрики, батарея, последняя активность (полный экран — фаза 3).
- **Сценарии**: список и конструктор «Если … То …» с предпросмотром из фразы (полный — фаза 5).
- **Память**: фаза 5. **Настройки**: «Интерфейс» (тема, подвижность ядра, слияние), «Медиа», автозапуск.

## Состояния (везде)

Загрузка — скелетоны; пусто — короткий текст; ошибка — текст и «Повторить»; офлайн — ядро
«Нет связи» с пояснением; сервер без proto 2 — «сервер не поддерживает».

## Снимки экранов

`cd desktop\ui; npm run build; npm run screens -- C:\sakura-tmp\screens` — Electron открывает
собранный интерфейс с демо-данными (`?demo=normal|empty|offline`) и сохраняет
`<экран>_<состояние>[_sketch]_<ширина>x<высота>.png` для 1440×1024 и 1180×760, обе темы.
Раскладка пишется во временный `layout.json`, настоящий файл не трогается.
