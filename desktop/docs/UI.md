## Окно

- Базовый размер 1536×1024 (не больше рабочей области экрана), минимум 1180×760.
- Без системной рамки, свой заголовок, скругление 14 px, масштабирование по DPI (Electron).
- Перетаскивание за заголовок (`.drag`), кнопки и вкладки — `.no-drag`.

## Заголовок (высота 64 px)

`[цветок-логотип] SAKURA / Your AI companion` · вкладки **Главная · Устройства ·
Сценарии · Настройки** (активная — `accent` на `accent-soft` со свечением) ·
справа `● Система активна` (зелёная точка) · кнопки свернуть / развернуть
(восстановить) / закрыть (красится в `accent` при наведении).

Логотип — SVG из 5 лепестков с выемкой на кончике (`SakuraLogo.tsx`).

- Сообщения показываются текстом: абзацы, нумерованные списки и эмодзи как есть,

- Карточка персонажа и маскот — заглушки (градиент + силуэт); файл
  `src/assets/character.png` заменит владелец.

## Остальные экраны

- **Устройства**: карточки устройств, метрики, батарея, фокус, вкл/выкл
  уведомлений, переименование, история (последние 20 событий).
- **Сценарии**: список (название, условие кратко, вкл/выкл, Запустить,
  Изменить, Удалить), конструктор, создание из фразы с предпросмотром,
  журнал запусков.
- **Память**: поиск, категории со счётчиками, просмотр, правка и удаление
  (только после подтверждения). Данные памяти не логируются и не кэшируются.
- **Профиль**: имя, обращение, часы тишины, голос и тон, уведомления,
  привязанные устройства.
- **Настройки**: микрофон и вывод, чувствительность слова «Сакура», модель
  распознавания, автозапуск, игровой режим, расширение браузера, быстрые
  подсказки, язык, тема, горячая клавиша «говорить сейчас», сброс, версия и
  «Открыть папку логов».

## Состояния (везде)

Загрузка — скелетоны; пусто — короткий текст и действие; ошибка — понятный
текст и кнопка «Повторить»; офлайн — баннер «нет связи с сервером»; сервер
без proto 2 — «сервер не поддерживает».

## Снимки экранов

`cd desktop\ui; npm run build; npm run screens -- C:\sakura-tmp\screens` — Electron открывает
собранный интерфейс с демо-данными (`?demo=normal|empty|offline|unsupported`, фикстуры
`desktop/tools/fixtures`) и сохраняет `home_<состояние>_<ширина>x<высота>.png` для 1536×1024 и
1180×760. Снимается только окно приложения (`capturePage`), не весь экран.
