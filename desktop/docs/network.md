# Сеть: YouTube во встроенном плеере

## Как встроен плеер

- Окно Sakura показывает страницу `http://127.0.0.1:<порт>/youtube/player.html?v=<id>&t=<токен>`
  с локального `media_server`. Не `file://`: с ним YouTube отвечает ошибкой 153
  (нет корректного источника встраивания).
- На странице — официальный iframe `https://www.youtube.com/embed/<id>?enablejsapi=1&origin=http://127.0.0.1:<порт>`
  с `referrerpolicy="strict-origin-when-cross-origin"` и YouTube IFrame Player API.
  Referer не убирается.
- Управление — только официальными методами API (play/pause/seek/rate/volume) через
  `postMessage` между окном Sakura и страницей плеера. Во фрейм youtube.com ничего не
  внедряется, поверх плеера ничего не рисуется, реклама показывается как есть.
- Ошибки встраивания 101/150 (владелец запретил встраивание) → кнопка «Открыть в браузере»
  (то же место видео). Ошибка 2 — неверный id, 5 — HTML5-ошибка, 100 — видео удалено.

## Режимы

`YOUTUBE_MODE=embedded` (по умолчанию) — видео открывается во встроенном плеере;
`remote` — команды идут во вкладку браузера через расширение (как в старом агенте).
«Взять из браузера»: расширение отдаёт `video_id` и `currentTime`, вкладка ставится на паузу.
«Вернуть в браузер»: открывается `https://www.youtube.com/watch?v=<id>&t=<сек>s`.

## Прокси только для плеера

`YOUTUBE_PROXY=http://host:port` (или `socks5://…`). Electron назначает его PAC-скриптом
только для доменов `youtube.com`, `youtube-nocookie.com`, `ytimg.com`, `googlevideo.com`,
`ggpht.com`; остальное приложение (локальный API, медиасервер, обновления) идёт напрямую.
Права администратора не нужны; системные настройки сети не меняются; Zapret/WinDivert/VPN
не встраиваются.

## Самопроверка

При открытии экрана «Видео» и на диагностической странице ядро проверяет доступность
`https://www.youtube.com/generate_204` и `https://i.ytimg.com/generate_204` (через прокси,
если он задан) и показывает результат по каждому адресу.

## CSP окна

`frame-src http://127.0.0.1:*` (страница плеера), `media-src 'self' http://127.0.0.1:* https: blob:`
(локальные файлы через медиасервер, ссылки на потоки), `connect-src … https:` (hls.js
загружает плейлисты .m3u8 и сегменты), `img-src … https:` (обложки Яндекс.Музыки).
Остальное — только `'self'`.
