# Возможности, зависящие от сервера: аудит (16.10.2026)

Окно различает ответы сервера (store.ts: `errorKind`, `errorText`):

| Вид | Коды ответа | Текст для пользователя |
|---|---|---|
| ещё не поддерживает | `unsupported`, `unknown_type`, `unknown_command`, сервер v1 | «Сервер ещё не поддерживает» (на экране — с названием раздела) |
| нужен защищённый канал | `secure_channel_required` | «Нужен защищённый канал: включи VPN или подключи устройство (Настройки → Безопасность)» |
| не отвечает | `timeout` | «Сервер не отвечает» |
| нет связи | `offline`, `core_offline` | «Нет связи с сервером» / «с ядром» |
| ошибка | всё остальное | текст сервера (`not_found` — «запись не найдена» и т.п.) |

Приватные классы `chat_*`, `history_*`, `memory_*`, `profile_*`, `vision_request` сервер отдаёт только по защищённому
каналу (PROTOCOL.md §5.1) — без него ответ «нужен защищённый канал».

| Экран / функция | Сообщение серверу | Мок-сервер | Сервер сейчас (v2) | Состояние в окне |
|---|---|---|---|---|
| Чат: история | `history_request` {limit, before_ts} | да | да (порция 1) | готово; подгрузка вверх — «Загрузить раньше» |
| Чат: поиск | `history_search` {q} | да | нет | «Сервер ещё не поддерживает» |
| Чат: удалить сообщение | `history_delete` {id} | да | нет | подтверждение «Удалить?»; на сервере — «ещё не поддерживает» |
| Чат: экспорт | — (локально, загруженные сообщения) | — | — | готово (диалог сохранения) |
| Устройства | `devices_request`, события `device_update` | да | да (порция 2) | готово |
| Статус | `status_request` | да | да | готово |
| Сценарии: список | `scenarios_list` | да | нет | «ещё не поддерживает» |
| Сценарии: из фразы | `scenario_from_text` | да | нет | «ещё не поддерживает» |
| Сценарии: запуск и журнал | `scenario_run`, события `scenario_event` | да | частично («Фокус») | готово: журнал по шагам |
| Сценарии: удалить | `scenario_delete` | да | нет | подтверждение «Удалить?» |
| Память | `memory_list/search/update/delete` | да | нет | категории, поиск, правка, удаление с подтверждением; без кэша на диск |
| Профиль | `profile_get/set` | да | нет | готово |
| Спросить про окно | `vision_request` | нет | да (приватный) | без защищённого канала — подсказка про VPN/Безопасность |
| Устройства канала | `secure_devices` | нет | /devices в Telegram | «Сервер ещё не поддерживает список устройств» |

**Ждёт сервер:** `history_search`, `history_delete`, `scenarios_list`, `scenario_from_text`, `scenario_delete`,
`memory_*`, `profile_*`, `secure_devices`. Экраны включатся без правок клиента, как только сервер начнёт отвечать.
