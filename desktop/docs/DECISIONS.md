### Варианты шифрования канала клиент ↔ сервер (к №43)

| Вариант | Что нужно на сервере | Защита | Минусы |
|---|---|---|---|
| ws:// (сейчас) | ничего | нет: токен и голос идут открыто | перехват и подмена в сети |
| wss:// с сертификатом от УЦ (Let's Encrypt) | домен, nginx/caddy с TLS перед WS | шифрование, проверка сервера по имени | нужен домен; при блокировках — уязвим к DPI по SNI |
| wss:// с самоподписанным сертификатом + SERVER_CERT_SHA256 | TLS на сервере, отпечаток в .env клиента | шифрование, сервер проверяется по отпечатку | смена сертификата — обновить отпечаток у клиентов |
| Noise (XX/IK) поверх TCP | свой обработчик рукопожатия, статический ключ сервера | шифрование и взаимная проверка ключей без УЦ | своя реализация на обеих сторонах; в клиенте пока заглушка |
| Туннель (WireGuard/VPN) до сервера | WireGuard на VPS | шифрует весь трафик | требует прав администратора на клиенте — по правилам проекта нельзя |
