## Подключение к живому ядру и серверу v1 (2026-10-12)
**Как запускать**
- `desktop\start_dev.bat` — проверки (старый агент не запущен; в agent\.env есть WS_TOKEN и DEVICE_ID — только булево; модели Vosk из C:\sakura-gitgent через SAKURA_MODELS_DIR; GigaAM из общего кэша), затем ядро `python -m desktop.core --headless` из venv агента, ожидание ui.token, `npm run dev`, проверка `python -m desktop.tools.core_check`.
  Если старый агент работает — скрипт спрашивает «да/нет» и без «да» не стартует. `-CheckOnly` — только проверки.
- Альтернатива: `SAKURA_CORE_AUTOSTART=1` и `SAKURA_PYTHON=<python>` — ядро запускает сам Electron (надзор, перезапуск до 3 раз за 5 минут).
