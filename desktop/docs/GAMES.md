# Игры, сцена и экран Сакуры

## Экран Сакуры (`core/screens.py`, `ui/electron/displays.ts`)

Мониторов может быть несколько. Настройки → «Экран и сцена» → «Экран Сакуры»: выбранный монитор
- снимается для зрения, «скажи, когда…» (Lookout + OCR Windows), игрового анализа и клипов;
- несёт сцену — прозрачный оверлей с рисованием, субтитрами и игровыми всплывашками.

Выбор хранится дважды: в `stage.json` (куда Electron ставит окно сцены) и в настройке ядра
`target_display` (границы в физических пикселях). Отключили монитор — сцена уходит на основной.
Кнопка «Проверить» обводит центр выбранного монитора на 4 с.

Координаты рисования (Ink) — в пикселях последнего снимка, который видела модель (`ink_space`):
сцена сама пересчитывает их в свои, DPI и уменьшение снимка не мешают.

## Сцена (`ui/src/stage/`, окно `?view=stage`)

Прозрачное окно на весь выбранный монитор: клики насквозь, фокус не забирает, в Alt+Tab не видно.
Показывается, только когда есть что показать (пустое окно поверх игры заставило бы Windows
компоновать кадр игры). В игре main раз в 1.5 с возвращает её наверх.

Показывает: рисование (`ink_render`), субтитры реплик Сакуры (в игре — всегда, вне игр — по настройке),
игровые всплывашки (`game_event`), уведомления в игре, маленькое ядро, пока она слушает/думает/говорит.

## Полноэкранные игры (`core/fullscreen.py`)

| Режим игры | Сцена поверх |
|---|---|
| Оконный без рамки | да |
| «Полноэкранный» DX11/DX12 с оптимизациями (FSO, по умолчанию в Windows 10/11) | да, почти всегда |
| Эксклюзивный (DX9, FSO выключены, часть Vulkan/OpenGL) | нет — только внедрением в игру, его не делаем (античиты) |

Эксклюзивный режим ядро узнаёт у Windows (`SHQueryUserNotificationState`). Если у игры стоит
«Отключить оптимизацию во весь экран» (флаг `DISABLEDXMAXIMIZEDWINDOWEDMODE`) или FSO выключены
глобально (`GameDVR_FSEBehaviorMode = 2`), Сакура предлагает включить их — только по кнопке
(HKCU, без прав администратора). Иначе — совет «оконный без рамки» и сцена на втором мониторе.

## Игры (`core/game_detect.py`, `game_director.py`, `game_presence.py`, `game_integrations.py`)

Игра определяется по процессу активного окна: список Мастера → папки лаунчеров (Steam, Epic, GOG,
Riot, Battle.net, EA, Ubisoft, Xbox, VK Play, Lesta…) и эмуляторы → «во весь экран + GPU».
Лаунчеры, браузеры и оверлеи игрой не считаются. «Это игра / не игра» — Настройки → «Игры».

Уровень присутствия — для каждой игры (по умолчанию «Реакции»):

| Уровень | Голосом | Пауза между репликами |
|---|---|---|
| Молчит | никогда (всплывашки и итоги — да) | — |
| Реакции | победа, поражение, серия, эйс, достижение, тильт | 45 с (важное — 5 с) |
| Комментатор | + смерть, убийство, раунды, бомба, цели | 18 с |
| Напарник | + урон, вспышки, затемнение, начало сессии | 8 с |

Источники событий: GameSense (локально по кадрам, ~6 к/с), CS2/Dota 2 Game State Integration
(файл cfg по кнопке «Подключить», порт 127.0.0.1:3017), League of Legends Live Client (само).
Тильт: 4 смерти за 10 минут → одна поддерживающая реплика (не чаще раза в 15 мин).
Автоклипы: победа, эйс, серия → последние 20 с в MP4. Пока Сакура говорит, игра приглушается до 40 %.

Сервер (`modules/game_sessions.py`, `sakura_core/ws_protocol.py`): `game_session_start` / `game_event` /
`game_session_end` → короткая реплика в характере (VOICE_MODEL_CHAIN), память сессий
`data/game_sessions.json` («в прошлый раз…» при следующем запуске, если прошло больше 3 часов),
итог сессии длиннее 10 минут. Полноэкранная игра больше не включает тишину на 30 минут, если уровень
игры не «Молчит».
