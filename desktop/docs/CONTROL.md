## Шаг 1 (сделано): честность результатов

- Единый контракт результата команды `{ok, status: done|noop|failed|unsupported, detail}`
  (`desktop/core/results.py`), во всех ветках `agent._run_command`. ok=true только при done.
  Старые исполнители (строки) классифицируются по признакам неудачи («не найдена», «неизвестная»,
  «нет активного плеера», пустой результат → не done).
- YouTube без расширения: клика мышью и переключения на окно Opera больше нет.
- close_window.браузер — по процессу и классу; youtube.trending — открытие страницы;
  чайник — наблюдение только после успеха, ключ по абсолютному пути, «не сопряжён» — не ошибка
  (и ключ больше не пишется в лог).
- Серверу: «Готово» — только при status=done, иначе «Не получилось: <detail>» (меняет серверный агент).

## Сквозные дефекты (касаются многих строк) — состояние до шага 1

1. **Ложный успех** — *исправлено на шаге 1.* Серверу уходит `ok: true`, когда действие не выполнено: ветка SMTC
   (`"ok": True` вместо `result["ok"]`), YouTube (`_send_ack(True, …)`), запасной путь
   `execute_command` («Opera не найдена», «неизвестная команда» → ok), ошибки расширения
   (`result.get("result", "ok")`). Сервер и чат говорят «Готово», а ничего не произошло.
2. **Горячие клавиши только для Opera.** `OPERA_TITLES`: Chrome, Edge, Yandex и Firefox без
   расширения не управляются.
3. **Клавиши в чужое окно** — *для YouTube исправлено на шаге 1; для музыки — шаг 3 (SMTC).* Музыкальные клавиши и запасной путь YouTube при отсутствии нужной
   вкладки уходят в «любое окно Opera» (а YouTube ещё и с кликом мышью).
4. **Чайник** — *исправлено на шаге 1:* наблюдение «чайник вскипел» запускается после `boil`, даже если команда не
   удалась (`a and b or c` — приоритет операторов).

## План починки (шаг 3, после «да»), с решениями владельца от 12.10

- Музыка без токена: shuffle/repeat/seek ± — SMTC (TryChangeShuffleActiveAsync,
  TryChangeAutoRepeatModeAsync, TryChangePlaybackPositionAsync); prev/restart — команды сессии;
  like/dislike — UI Automation приложения Я.Музыки, иначе честный отказ «нужен токен»;
  music.volume_up/down/mute — громкость **сессии** Я.Музыки (pycaw ISimpleAudioVolume, шаг VOLUME_STEP);
  system.volume — общая громкость; запасного «клавишу в Opera» нет.
- Выключение/перезагрузка — `shutdown /s|/r /t 30`, голосовое предупреждение «Выключаю через
  30 секунд, скажи “отмени”» и тост «Отмена» с обратным отсчётом; shutdown_cancel — `shutdown /a`.
- Сон — `SetSuspendState(False, True, False)` через ctypes (не rundll32). Живьём не проверяется:
  при включённой гибернации rundll32 SetSuspendState 0,1,0 гибернирует, потому что rundll32
  передаёт строку, а не три BOOL; прямой вызов API с bHibernate=False уводит именно в сон.
