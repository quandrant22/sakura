# Яндекс.Музыка по токену — что доступно

Проверено 15.10.2026 кнопкой «Проверить токен» (`ym_token_check`, `desktop/core/media/yandex_api.py`).
Только счётчики и статусы; содержимое библиотеки не публикуется. Библиотека yandex-music 3.2.1 (LGPLv3) —
только вызывается; API неофициальный, ответы меняются (в журнале бывает «API response does not match the
library model» для поиска — данные при этом приходят). ClientAsync требует aiohttp, которого нет в venv агента, —
используется синхронный Client в потоке (DECISIONS №48).

не воспроизводится. Ошибки 401/403/сети — статус «недоступно», панель не падает.
