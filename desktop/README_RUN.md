# Как запускать Сакуру

> Разделы о запуске ярлыком, остановке и логах появятся вместе с Sakura.bat.

## Доступ к Яндекс.Музыке (лайки, дизлайки, текст песни)

1. Откройте файл `C:\sakura-git\agent\.env` в Блокноте.
2. Добавьте строку `YANDEX_MUSIC_TOKEN=ваш_токен`.
3. Сохраните файл и перезапустите Сакуру (трей → «Выход», затем снова ярлык Sakura).

Без токена кнопки «Нравится», «Не нравится» и «Текст» приглушены и по клику объясняют, что сделать.
Сакура не показывает значение токена, не пишет его в журнал и не отправляет на сервер.

Для подкастов так же добавьте `YANDEX_UID=ваш_id`.
