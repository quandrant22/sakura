# Sakura Mobile 🌸📱

Официальный мобильный клиент-компаньон для экосистемы **Сакура** (iOS & Android).

---

## 🚀 Возможности приложения

1. **💬 Чат и голос (Главный хаб)**
   * Живой текстовый диалог с Сакурой с мгновенной доставкой через WebSocket.
   * **Push-to-Talk (Микрофон):** голосовой ввод с удержанием кнопки и тактильным откликом (`expo-haptics`).
   * **Динамический HUD Сакуры:** анимированный визуализатор ядра (состояния `idle`, `listening`, `thinking`, `speaking`, нимб настроения и тональность).
   * Оффлайн-баннер с быстрым переходом в настройки при потере связи.

2. **📡 Сеть и мультидевайс**
   * Мониторинг всех устройств экосистемы Сакуры (`pc`, `laptop`, `mostech`, `phone`).
   * Отображение активного фокуса Мастера, уровней заряда батарей, Wi-Fi сетей и статусов онлайн/оффлайн.
   * Автоматическая передача телеметрии смартфона в периодическом Heartbeat (`ping`).

3. **🧠 Долговременная память**
   * Доступ к базе знаний Сакуры: предпочтения, факты, закладки.
   * Мгновенный поиск по ключевым словам через `memory_search`.
   * Удаление и редактирование записей прямо с телефона.

4. **⚙️ Сценарии и рутины**
   * Список автоматических сценариев (`scenarios_list`).
   * Запуск сценариев в один клик с отслеживанием прогресса выполнения.

5. **🌸 Настройки связи и профиль**
   * Подключение к VPS Сакуры по защищённому WSS-каналу с токеном `WS_TOKEN`.
   * Автоматический реконнект с экспоненциальной задержкой.
   * Отображение настроек характера и профиля (обращение, тон, голос, тихие часы).

---

## 🛠️ Стек технологий

* **Фреймворк:** React Native 0.88 + Expo SDK 58
* **Маршрутизация:** Expo Router v58 (файловый роутинг в `src/app/(tabs)`)
* **Язык:** TypeScript (строгая типизация)
* **Стейт-менеджмент:** Zustand (единообразно с `desktop/ui`)
* **Хранилище настроек:** `@react-native-async-storage/async-storage`
* **Анимации и жесты:** `react-native-reanimated`, `react-native-gesture-handler`
* **Сенсоры и обратная связь:** `expo-haptics`, `expo-battery`, `expo-network`

## 📱 Быстрый запуск

### 1. Запуск сервера разработки
```powershell
cd mobile
npm.cmd start
```

### 2. Запуск на физическом телефоне (Expo Go)
1. Установите приложение **Expo Go**:
   * [Google Play (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)
   * [App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)
2. Запустите `npm.cmd start`.
3. Отсканируйте появившийся в терминале QR-код камерой iPhone или через Expo Go на Android.

### 3. Проверка типов и сборки
```powershell
cd mobile
npx.cmd tsc --noEmit
```

## 🔐 Подключение к серверу Сакуры

1. Перейдите во вкладку **«Связь» (🌸)** в приложении.
2. Введите WebSocket URL вашего VPS (например, `wss://sakura.mydomain.com/ws` или локальный адрес для теста `ws://192.168.1.x:8765`).
3. Введите ваш `WS_TOKEN`.
4. Нажмите **«Подключиться»**. Статус изменится на **«Подключено (v2)»**, и Сакура станет доступна в кармане!
