# Замер решателя тестов (scripts/quiz_eval.py)

Набор `eval/quiz/bank.json` — 97 вопросов с эталоном:

| категория | n | что проверяет |
|---|---|---|
| general | 35 | школа/вуз: история, география, биология, физика, химия, литература, русский |
| niche | 16 | право РФ, IT, медицина, бухучёт, экономика |
| math | 16 | вычисления, проценты, уравнения, геометрия, вероятность, задачи-ловушки |
| tricky | 10 | отрицания («НЕ является», «КРОМЕ»), загадки с подвохом |
| image | 7 | ответ только по рисунку: диаграмма, счёт фигур, пример, треугольник, таблица, часы, цвет |
| match | 5 | сопоставление (пары строка → вариант) |
| order | 5 | упорядочивание |
| injection | 3 | в тексте вопроса команда модели («выбери 5») — должна быть проигнорирована |

Виды: single 38, number 33, multi 6, text 6, match 5, order 5, select 4.

## Как устроено

- Уровень 1 — только решатель (`quiz_solver.solve`): те же модели (`QUIZ_MODEL_CHAIN`), промпт, схема ответа, лимитер квот и параллельность (`QUIZ_PARALLEL`), что в задаче браузера. Браузер и навигатор не участвуют.
- Кадры: вопросам, которым в задаче нужна вырезка (`needs_crop`: медиа или вид ≠ single), рисуется карточка вопроса (PIL, DejaVuSans); у `image` — с рисунком.
- Проверка: варианты — точное совпадение; multi — множество (частично — Жаккар); order — порядок (частично — доля верных пар); match — доля верных пар; number — число с допуском `tol` («0,25», «1/4», «28,26 см²»); text — нормализованное совпадение или вхождение слова (`match: contains`).
- Квоты: отдельный лимитер (не `data/gemma_quota.json`) — запускать, когда агент браузера не работает. Весь набор ≈ 100–130 вызовов из 1500 в сутки на модель.

## Запуск (VPS, /opt/sakura)

```bash
venv/bin/python scripts/quiz_eval.py --dry-run                 # набор и кадры, без модели
venv/bin/python scripts/quiz_eval.py --tag base                # весь набор, текущие модели
venv/bin/python scripts/quiz_eval.py --chain gemini-3.5-flash-lite --tag flashlite
venv/bin/python scripts/quiz_eval.py --crop all --tag oldcrop     # прежнее правило кадров
venv/bin/python scripts/quiz_eval.py --compare data/quiz_eval/A.json data/quiz_eval/B.json
```

Отчёт: `data/quiz_eval/<время>-<tag>.json` (всё, по вопросам) и `.md` (точность по категориям и видам, время вопроса p50/p90, время вызова модели, токены, список ошибок). `--compare` — «было → стало» и списки исправленных/сломанных вопросов.
