# PARITY — функции десктопа на телефоне

Каждая строка `desktop/docs/PARITY.md` (ветка origin/feat/desktop-integrated): **на телефоне** — делает приложение; **через пульт** — телефон запускает, исполняет ПК (кнопка `action_run` с `device` или фраза голосом/текстом); **не применимо** — функции нет смысла на телефоне.
