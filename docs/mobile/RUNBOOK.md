# RUNBOOK — ручные проверки на телефоне (Android 16) и реальном сервере

Агент живых проверок не выполнял: всё ниже — для владельца. Условие для пунктов 3–9: на сервере выкачена
ветка server/phone (Noise `SECURE_CHANNEL=optional|required`, `phone` в `MASTER_DEVICES`, phone.* в реестре).
Пока её нет, приложение должно честно показывать «Сервер ещё не поддерживает…», баннеры «нет прав master» /
«не поддерживает приложение телефона» и `secure_channel_required` — это тоже проверка (п. 10).

## 1. APK

```
cd mobile\android
set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
gradlew.bat testDebugUnitTest verifyPaparazziDebug lint assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Release (R8, без Log.d/v) подписывается своим ключом: создать `keystore.jks` вне репозитория
(`*.jks` в .gitignore), подписать `apksigner sign --ks keystore.jks app-release-unsigned.apk`.
Проверка AGSL на устройстве: `gradlew.bat connectedDebugAndroidTest` (тест `CoreShaderInstrumentedTest`;
в logcat тег `CoreShader` — время кадра, бюджет ≤ 4 мс).

## 2. Спаривание (/pair)

1. В Telegram: `/pair` → QR, 8 слов и отпечаток ключа сервера.
2. Телефон: «Ещё → Безопасность → Спарить по QR» → навести на QR.
   Ожидание: диалог «Спарено» с отпечатком; **сверить отпечаток** с Telegram (группы по 4 hex).
3. Вариант: «Ввести 8 слов» — адрес `ws://<IP>:8765` и слова через пробел/дефис (регистр и «ё» не важны).
4. Неверные слова → «сервер отклонил код…» примерно через 5 с; в Telegram попытка засчитана.
5. Просроченный QR → «срок кода спаривания истёк — получите новый в Telegram (/pair)».
6. После спаривания статус «Онлайн», в Telegram `/devices` — `phone`, secure.

## 3. Команды phone.* (сервер шлёт `command`)

Сказать на ПК или в Telegram фразу из реестра; на телефоне — результат, в журнале сервера `command_result`.

| действие | фраза-пример | ожидание | без разрешения |
|---|---|---|---|
| phone.find | «найди телефон» | 30 с громкий сигнал будильника, громкость возвращается | — |
| phone.dnd_on / dnd_off | «включи не беспокоить на телефоне» | режим «Не беспокоить» вкл/выкл | unsupported «нет разрешения: Режим «Не беспокоить»» + уведомление → «Разрешения» |
| phone.alarm | «поставь будильник на телефоне на 7:30» | будильник 07:30 без экрана часов | при закрытом приложении без «поверх окон» — unsupported |
| phone.timer | «засеки на телефоне 5 минут» | таймер 300 с | как выше |
| phone.flashlight | «включи фонарик» / «выключи фонарик» | вспышка вкл/выкл | на телефоне без вспышки — unsupported |
| phone.volume | «громкость телефона 40» | громкость медиа 40 % | — |
| phone.clipboard | «скопируй на телефон …» | текст в буфере, уведомление «Скопировано с компьютера» | — |
| phone.open_url | «открой на телефоне сайт …» | ссылка в браузере | как alarm |
| phone.open_app | «открой на телефоне телеграм» | приложение запущено (нечёткий поиск) | как alarm; нет приложения — noop |
| phone.media_* | «пауза на телефоне», «следующий трек на телефоне» | плеер телефона реагирует | — |
| phone.notify | «пришли на телефон уведомление …» | уведомление в канале «Сакура» | unsupported «нет разрешения: Уведомления» |

Офлайн-путь: выключить сеть, сказать «включи фонарик» — фонарик включается, под ядром
«Без связи — на телефоне: фонарик включён»; после появления сети фраза серверу **не** уходит.

## 4. Голос

1. Тап по ядру → «Слушаю», живой транскрипт под ядром; фраза → «Думаю» → «Говорю» (озвучка, уровень на ядре).
2. Удержание ядра ≥ 0,6 с — PTT с вибрацией; отпустить — финал распознавания.
3. Перебивание: во время озвучки тап по ядру / кнопка гарнитуры — озвучка обрывается сразу, хвост не доигрывает.
4. «Ещё → Голос → Скачать модель» (46 МБ, SHA-256) → включить «Слушать „Сакура“» → «Сакура» при открытом
   приложении открывает микрофон. Во время озвучки — только с гарнитурой или при AEC.
5. Дослушивание: вопрос Сакуры («…?») → микрофон открыт ещё 6 с без слова; ползунок 0–15 с.
6. «Ответы текстом» или беззвучный режим → ответ без звука (в журнале сервера `speak:false`).
7. «Ещё → Диагностика»: разрывы озвучки 0 на Wi-Fi, распознавание «на устройстве».

## 5. Подтверждение питания

1. «Пульт» → выбрать ПК → «Выключить». Ожидание: `action_started`, затем диалог «Сакура спрашивает:
   Выключить игровой компьютер? Да или нет?».
2. «Нет» → «Хорошо, не выключаю». «Да» → ПК выключается (в журнале `voice_command` «да», channel `text`).
3. Без связи «Да» не копится (outbox не принимает ответы на confirm).

## 6. Ассистент

1. Настройки Android → Приложения по умолчанию → Цифровой ассистент → «Сакура».
2. Долгое нажатие питания → нижняя панель с ядром, сразу «Слушаю»; ответ текстом в панели и голосом.
3. На заблокированном экране: только голос и ответ, кнопки «Открыть» нет, чата нет.
4. Без «Всегда на связи» связь опускается через 30 с после закрытия панели (в журнале сервера `bye exit`).

## 7. Плитка, виджет, плавающее ядро, Share, «Что это?»

- Плитка «Сакура» в шторке → открывает приложение и слушает.
- Виджет: тап по ядру — слушать; три кнопки — action_run на активный ПК (ошибка — уведомлением).
- «Ещё → Интерфейс → Плавающее ядро» → разрешение «поверх окон» → ядро 56dp поверх приложений, состояния
  меняются; перетащить — прилипает к краю; бросить на «×» внизу — исчезает и выключается.
- Share: из браузера «Поделиться → Отправить Сакуре» (текст) → в чате «Мастер поделился: …»;
  картинка → ответ Сакуры о картинке в окне.
- «Диалог → камера» → «Что это?» → ответ по кадру; в галерее и файлах приложения кадра нет.

## 8. Всегда на связи

«Ещё → Безопасность → Всегда на связи» → уведомление «Сакура · Онлайн» с кнопками «Говорить» / «Отключиться»;
свернуть приложение — связь держится, команды phone.* исполняются. «Отключиться» — служба и связь закрыты.

## 9. Отказ неизвестному ключу

1. В Telegram `/revoke phone` (или «Забыть сервер» на телефоне без отзыва на сервере — новый ключ).
2. Телефон пытается подключиться: сервер молчит и закрывает **4408 ровно через 5 с**; на телефоне «Нет связи»,
   в «Диагностике» «последнее закрытие 4408 · сервер не узнал устройство — спарьте заново (/pair)».
   Переподключения идут с паузами 1→30 с, не чаще.
3. В журнале сервера — отпечаток ключа и код, без ключей и payload.

## 10. Сервер без server/phone

- Сервер v1 / без proto 2 → баннер «Сервер ещё не поддерживает приложение телефона…», экраны «Сервер ещё не
  поддерживает …», голос и текст работают.
- `phone` не в `MASTER_DEVICES` → баннер «не выдал прав master», пульт — текст ошибки сервера (`not_master`).
- Приватные классы без secure → «Нужен защищённый канал: включи VPN или подключи устройство (Настройки → Безопасность)».
