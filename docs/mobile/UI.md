# UI телефона — токены, темы, экраны, анимации

Источник токенов — `desktop/docs/UI.md` и `desktop/ui/src/index.css`. В разметке цвета только через
`?attr/…` и `@color/…` — проверяет `CoreTokensTest` (запрещены `#RRGGBB` и `@android:color` в `res/layout*`).

Размеры (`dimens.xml`): карточки 20dp, кнопки 12dp, ядро 220dp / 96dp / плавающее 56dp, сдвиг пузыря 8dp.
Темы: `Theme.Sakura.Night` (по умолчанию), `Theme.Sakura.Sketch`; переключение — «Ещё → Интерфейс».

## Ядро

`CoreFrame.java` — порт `coreFrame.ts` один в один (DROP_R, SATELLITES, WOBBLE, ORBIT_SPEED, VIEWBOX,
MAX_RING_R, MERGE_PRESETS, MOBILITY). `SakuraCoreView`: AGSL-метаболы (капля + 5 спутников, порог по пресету,
радиальный градиент accent→accent_deep из (−21.5, −17), r 71.4), 2 кольца 2dp, свечение accent_soft; fps
idle 30, активные 60, offline 10 через Choreographer; уровень — `onRmsChanged` и RMS чанков; «Убрать анимации» —
статичный кадр. На программном холсте (снимки, виджет) — та же формула на CPU (D19, D22).

## Экраны

Нижняя навигация: **Диалог**, **Пульт**, **Сводка**, **Сценарии**, **Ещё** (Память, Профиль, Голос, Безопасность,
Интерфейс, Разрешения, Диагностика). Состояния везде: скелетон, пусто, ошибка с «Повторить», офлайн
(«Нет связи с сервером»). Тексты ошибок — дословно SERVER_FEATURES.md (`ErrorText`).

| экран | содержимое |
|---|---|
| Диалог | ядро и статус (Онлайн / Слушаю / Думаю / Говорю / Нет связи), транскрипт, чат (пузыри: Сакура — градиент, Мастер — panel2; метка канала и устройства), «Загрузить раньше», поиск, удаление (долгое нажатие), экспорт (Share sheet), «Что это?», поле ввода и микрофон (тап / удержание PTT) |
| Пульт | карточки ПК (в сети, активный, CPU/RAM/GPU), мини-плеер по track, кнопки action_run с device |
| Сводка | статус, устройства (батарея телефона), события сценариев, последние ответы |
| Сценарии | список, запуск с журналом, удаление; конструктор «Если … То …» и «Из фразы» с предпросмотром |

## Анимации

| что | как |
|---|---|
| смена состояния ядра | интерполяция кадров 250 мс (smoothstep) |
| появление пузыря | fade + сдвиг 8dp, 150 мс (только новые push-сообщения) |
| экраны | fade 150 мс (`anim/screen_in|out`) |
| общий элемент | ядро «Диалог» → «Что это?» (`transitionName="core"`) |
| тактильный отклик | PTT (начало/конец), подтверждения и отказы |

«Убрать анимации» или системное отключение анимаций — без движения (`Motion.reduced()`).
