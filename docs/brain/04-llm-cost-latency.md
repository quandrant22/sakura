## 3. Надёжность цепочек

- **503 у flash-lite** — основная причина «все модели не ответили». Фолбэк в
  цепочке есть, но второй шаг часто gemma, которая сама падает (27 неудачных
  попыток). Для voice разумно: 3.5-flash-lite → 3.1-flash-lite → gemma
  (быстрые модели вперёд).
- **Классификатор на gemma** (chat-цепочка) — 1.0 / 3.8 с; один ход ждал
  вердикт 4.9 с. После этапа 0 таймаут шлюза 4 с, но вердикт по-прежнему на
  критическом пути.
- **daily_analysis** падает на разборе JSON (7 раз) — ответ модели не
  строго JSON; стоит `response_mime_type="application/json"`.
