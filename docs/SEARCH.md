# Поиск в интернете (sakura_core/search)

Один конвейер для всех путей, которым нужен интернет.

```
вопрос + канал (voice | text | tg | background)
   │
 1 context.resolve_subject   игра Steam → заголовок окна-игры → тема последнего взгляда на экран
 2 plan.make                 1 вызов модели (без thinking, потолок): сущность + ≤3 запроса
                             (по-русски, по-английски, «wiki»); сбой → запасной план
 3 pipeline._fetch           Parallel Search MCP (до 8 результатов, по страницам)
 4 rank.judge                модель-судья по заголовкам/выдержкам: только про эту сущность;
                             сбой → строгое правило по словам; ничего → пусто
 5 pages.read                дочитка лучшей страницы (основной текст, og:image) — text/tg
 6 Evidence                  ok, entity, queries, items, facts, sources, image_urls, timings
```

## Бюджеты по каналу

| канал | всего | план | судья | дочитка | факты |
|---|---|---|---|---|---|
| voice | 9 с | 3 с | 2,5 с | нет | 2500 |
| text | 18 с | 4 с | 4 с | да | 4000 |
| tg | 25 с | 4 с | 4 с | да | 5000 |
| background | 25 с | 4 с | нет (по словам) | нет | 3000 |

## Кто вызывает

| путь | канал | что передаёт |
|---|---|---|
| `llm.ask_gemini` (текст, Telegram-чат) | text | вопрос, подсказка продолжения разговора по экрану, разговор |
| `llm.ask_gemini_voice` | voice | то же |
| `vision.ask.answer` («глянь на экран») | voice | тема по заголовку окна, факты с экрана, запрос модели зрения как подсказка |
| `tg_share.share` («скинь в телегу») | tg | тема просьбы; картинки — из `image_urls` и страниц `items` |
| `web_search.search_and_fetch` / `smart_search` (автономные «исследования») | background | — |

`web_search.search_grounded` — прежний API Parallel, оставлен ради совместимости; ядро его не вызывает.

## Правила

- **Нет «ответов из памяти модели» под видом интернета.** Не нашли — `ok=False`, вызывающий говорит «не нашла».
- **Чужое не берём.** Сущность известна, подходящих страниц нет — пусто (хлопок: V Rising и статья про ткани отсеиваются).
- **Заголовок окна надёжнее зрения.** Название игры по окну, а не по догадке модели на кадре.
- **Кэш** 30 мин по (вопрос, сущность, глубина).
- **Журнал:** одна строка на поиск — `[search] канал=… тема=… план=model|fallback запросы=[…] найдено=N отобрано=M за T с {план, поиск, отбор, дочитка}`.

## Дальше
